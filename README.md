# JavaScript Practice 🚀

Basic se advanced tak JavaScript problems ki practice — is repo mein maine roz solve kiye gaye problems store kiye hain.

## 📂 Structure

```
js-practice/
├── 01-basics/       # variables, data types, operators, conditionals
├── 02-arrays/       # array methods, manipulation, sorting
├── 03-strings/      # string manipulation, palindrome, reverse etc.
├── 04-loops/        # for, while, nested loops, patterns
├── 05-functions/    # functions, closures, recursion
└── 06-dsa/          # data structures & algorithms
```

## ▶️ How to Run

Har file ek standalone JS file hai. Node.js installed hona chahiye.

```bash
node 01-basics/swap-numbers.js
```
